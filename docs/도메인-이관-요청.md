## 2. 받는 쪽(우리)이 할 일

신청이 오면 **7일 안에** 수락해야 한다. 넘기면 자동 취소되고 업체가 다시 신청해야 한다.

1. 안내 메일의 「도메인 받기」 클릭 → hosting.kr 로그인
2. 나의서비스 > 도메인관리 > **계정변경 - 나의 계정으로** 탭에서 수락
3. 수락하면서 **소유자 정보를 새로 입력** — 이 단계에서 명의가 DESIGNDAY → 우리 쪽으로 정리된다
   (이때 안 바꿔도 7일 안에는 추가 인증 없이 1회 더 변경 가능)

계정이 아직 없으면 먼저 가입: <https://login.megazone.com/signup?next=https://www.hosting.kr>
필요한 건 이메일·비밀번호·이름뿐. 서류 없음. 고객센터 1644-7378 (평일 09:00~18:00)
