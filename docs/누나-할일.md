# 누나가 할 일 (숲속의바다 홈페이지 새로 단장)

새 홈페이지는 이미 만들어져서 돌아가고 있어요. https://woodinsea.pages.dev
지금 쓰는 주소(woodinsea.com)를 새 홈페이지로 옮기는 일만 남았습니다.

지금 그 주소가 **홈페이지 만들어준 업체(DESIGNDAY) 명의**로 되어 있어서,
누나 앞으로 넘겨받아야 합니다. 서류는 필요 없습니다.

---

## 1. 호스팅케이알 계정 만들기

<https://login.megazone.com/signup?next=https://www.hosting.kr>

이메일, 비밀번호, 이름만 넣으면 끝입니다. 사업자등록증 같은 거 안 냅니다.
**여기 넣는 이메일이 앞으로 도메인 관련 안내를 받는 주소**가 되니,
평소에 확인하는 메일로 만들어 주세요.

## 2. 업체에 도메인 넘겨달라고 요청

따로 보내드린 문구를 그대로 복사해서 메일이나 카톡으로 보내시면 됩니다.
1번에서 만든 이메일 주소를 알려줘야 업체가 그쪽으로 보낼 수 있습니다.

## 3. 업체가 보내면 7일 안에 받기  ← 제일 중요

안내 메일이 오면 「도메인 받기」를 누르고 로그인해서 수락합니다.
**이때 소유자 정보를 우리 이름으로 새로 넣어 주세요.**
그냥 수락만 하면 명의가 업체 이름으로 남습니다.

7일이 지나면 자동 취소되고 업체가 처음부터 다시 신청해야 합니다.

## 4. 네임서버 바꾸기

동생이 주소 두 줄을 알려드릴 거예요. 그걸 호스팅케이알에 붙여넣으면 됩니다.
어디에 넣는지는 그림으로 알려드립니다.

## 5. 예약 사이트에 적힌 홈페이지 주소 바꾸기

네이버 플레이스, 야놀자, 여기어때 등에 적어 둔 홈페이지 주소를 새 주소로.
손님들이 실제로 들어오는 길이라 이게 제일 중요합니다.

## 6. 관리자 페이지 배우기

이제 **공지사항이랑 이벤트를 누나가 직접 올리고 지울 수 있습니다.**
동생한테 부탁 안 해도 됩니다. 준비되면 사용법 알려드릴게요.

## 혹시 업체가 안 넘겨준다고 하면

새 주소를 하나 사면 됩니다. 1~2만원이고 그날 바로 됩니다.
그러면 2·3·4번은 안 해도 되고 5번만 하면 됩니다.
새 홈페이지는 이미 잘 돌아가고 있으니 급할 거 없습니다.
